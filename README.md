# Muntafid Islam Nafsi - Portfolio

A responsive personal portfolio introducing Muntafid Islam Nafsi and highlighting selected web, database, and Android projects.

## Live site

[View the deployed portfolio](https://nafus-port-i8qcj9elf-muntafid-islam-nafsi-s-projects.vercel.app)

## Tech stack

- Next.js 14
- React 18
- TypeScript
- CSS Modules and global CSS
- Lucide React icons

## Features

- Responsive navigation with a mobile menu
- Hero, selected-work, about, and contact sections
- Interactive project selector for featured work
- Profile image and links to GitHub, LinkedIn, and email

## Run locally

```bash
git clone https://github.com/nafus08/Portfolio.git
cd Portfolio
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). To create a production build, run `npm run build` and then `npm start`.
